# Anim3D assets

`human-addon-animations.glb` — Mesh2Motion's human animation pack (a retarget of
the Quaternius Universal Animation Library), **CC0-1.0**, vendored unchanged from
`AssiamahS/opengym3d` (`motions/cc0/mesh2motion/`, commit `2d3d1ff`, 2026-09-04),
which in turn takes it from
[`Mesh2Motion/mesh2motion-app`](https://github.com/Mesh2Motion/mesh2motion-app)
(`static/animations`).

- Licence: CC0-1.0 (public domain dedication) — commercial use, modification and
  redistribution allowed. Keep this note for provenance, not obligation.
- sha256: `a0d64d555e0d492026b72d58bf8e16c5e86779295f9093e376dcc001915c2c95`
- Rig: UE mannequin, 68 bones, one skinned mesh (13,757 triangles), 75 clips.
- Clips we use: `Pushup`, `Jumping Jacks`, `Run_Anime`, `Fighting Left Jab`.

Nothing in this folder comes from Gym visual or openGym. Only the rig and the
motion are third-party; the rendering, camera, lighting and encode are ours.
